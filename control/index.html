LINUX
Ripristino e manutenzione

            

            

              

                Ripristino automatico GE360
                
sudo bash /opt/ge360/ge360-rilievi-backend/scripts/recover-linux-install.sh

              

              

                Reinstallazione Direct Bridge
                
sudo GE360_SERVICE_USER=ge360 bash /opt/ge360/ge360-rilievi-backend/scripts/install-direct-bridge.sh

              

              

                Verifica IPv6 pubblico
                
ip -6 addr show scope global

              

              

                Stato servizi GE360
                
ge360-rilievi-status

              

            

            
Sicurezza: non esporre TCP 9888 sul router. Il frontend remoto deve entrare tramite WireGuard e raggiungere il backend sulla rete privata GE360.
